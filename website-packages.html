How a project runs

Four stages, each with a clear sign-off, so you always know what is next.

  1. Brief and scope

    You share goals, pages and content. We send a fixed-scope proposal within one business day.

  2. Design

    Home page and one inner page are designed first. Approval releases the 30% milestone.

  3. Build and SEO

    Pages, forms and database work are built, then tuned for speed and search.

  4. Launch

    We test, connect your domain, set up analytics and go live with support included.

Package questions

Which package should a tour operator choose?

Most travel companies start with Travel & Tourism. It includes package, destination and itinerary page templates and an enquiry form that stores leads in MySQL.

Can I add pages later?

Yes. Because templates are reused, adding a new package or attraction page costs far less than the first one.

Is content writing included?

Layout and on-page SEO are included. Writing copy and sourcing photos can be added to any package, or you can send your own.

Can you move my existing site?

Yes. Migration with 301 redirects is part of the Custom plan and can be added to any other package so your rankings carry over.

What do I need to send before we start?

Your logo, brand colours if any, a list of pages, and any text and photos you already have. We help with the rest.

Need something that is not listed?

The Custom package covers dashboards, integrations and larger builds, quoted after a scope call.
