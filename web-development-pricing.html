Common questions

Should I choose fixed-price or hourly?

Choose fixed-price when the scope is clear. Choose hourly when requirements will change as you go or when the work is small fixes and updates.

What is included in monthly maintenance?

Code checks, content updates up to a monthly hour limit, backups, uptime monitoring and a short monthly report.

Can I buy add-ons after launch?

Yes. Add-ons are priced separately and can be built on any site, including ones PS Web Studio did not originally build, after a quick code review.

Do you work with existing websites?

Yes. Speed fixes, SEO cleanup, new pages and migrations are all available. A review of the current code comes first so the quote is accurate.
